# Monitoring and incidents

Container stdout/stderr and Caddy access logs are captured with bounded rotation. Require JSON application events with UTC time, level, event name, request/correlation ID, route template, status, latency and release. Never include request bodies, script text, cookies, Authorization, JWTs, object URLs, payment evidence, database URLs or supplier credentials. Caddy hides credential headers by default; keep that behavior. Validate redaction with synthetic sensitive strings before staging approval. The image loads `deploy/logging.json` and a conservative JSON formatter for Uvicorn that emits time, level, logger, event, HTTP method/status and exception type only; it omits URL, raw messages and tracebacks to avoid leaking request data. Application request IDs, route templates and latency instrumentation remain a release gate; server JSON output alone does not prove those metrics exist.

Sentry integration template (pending code/SDK wiring): `SENTRY_DSN`, `SENTRY_ENVIRONMENT`, `SENTRY_RELEASE`. Core configuration currently documents `DATABASE_URL`, `WORKER_DATABASE_URL`, `APP_ORIGIN`, `SUPABASE_ISSUER`, `SUPABASE_AUDIENCE`, `SUPABASE_JWKS_URL`, `S3_ENDPOINT_URL`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `CREDIT_PER_CHARACTER`, `SUPPLIER_ENABLED`. Do not invent that adding Sentry variables enables integration. A future SDK init must use `send_default_pii=False`, omit bodies and cookies, scrub headers/URLs and disable session replay; verify a synthetic event reaches a staging project without private data. Set release to image commit and sample traces conservatively. Do not use Sentry as a financial audit store.

Monitor public health separately from authenticated canaries. A 200 health response alone does not prove DB/R2/worker readiness. Alert on sustained API 5xx (>2% over 5m), p95 latency >2s for metadata endpoints over 10m, failed auth spikes, worker heartbeat absent >2m, oldest queued job >5m, any new uncertain supplier submission, ledger/reservation invariant failure, repeated manual payment approval conflict, R2 ingestion failures, expired-object backlog >48h and backup age >26h. Thresholds are proposed and need traffic calibration. Do not run paid generation in a health check.

On uncertain supplier execution: pause dispatch, preserve outbox and supplier request/reference IDs, independently inspect supplier execution, and only then append an authorized reconcile/refund event. Do not toggle a failed job back to queued or alter old ledger/audit rows. On audio leak: disable affected routes/credentials, preserve incident evidence, rotate scoped R2 credentials and retest ownership/expiry across GET/HEAD/Range. On credential disclosure: revoke/rotate at source, replace runtime env, restart affected services, invalidate relevant sessions, verify old credential fails and check history for misuse.
